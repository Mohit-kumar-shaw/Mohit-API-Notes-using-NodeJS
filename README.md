# Notes API

A RESTful Notes API built using Node.js and Express.js.  
This project performs CRUD operations such as GET, POST, PUT, PATCH, and DELETE.  
All API endpoints were tested using Postman and Thunder Client.

---

## Features

- Create Notes
- Read Notes
- Update Notes
- Delete Notes
- REST API Architecture
- JSON Data Handling
- API Testing with Postman & Thunder Client

---

## Tech Stack

- Node.js
- Express.js
- Postman
- Thunder Client

---

## Installation

1. Clone the repository

```bash
git clone https://github.com/Mohit-kumar-shaw/Mohit-API-Notes-using-NodeJS.git
```

2. Navigate to the project folder

```bash
cd notes-api
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
node index.js
```

---

## API Endpoints

| Method | Endpoint     | Description        |
|--------|--------------|-------------------|
| GET    | /notes       | Fetch all notes   |
| POST   | /notes       | Create a note     |
| PUT    | /notes/:id   | Update full note  |
| PATCH  | /notes/:id   | Update note data  |
| DELETE | /notes/:id   | Delete a note     |
